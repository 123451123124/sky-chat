# RAG、Agent 与 3D 来源图

2026-10-20：进阶链路与开源复用已落地，详见 [进阶改造说明](RAG进阶改造与开源复用.md)。Sky Chat 仍是标准聊天客户端，未增加 MCP 或产品 Skill。

## 使用

1. 管理员进入 `/admin/knowledge`，新建知识库。新建的知识库默认为草稿，其他账号不可见。
2. 批量选择或拖入文件；每批最多 50 个，最多同时上传 3 个。队列显示逐文件上传结果，单个失败不阻断其他文件，并可重试上传失败文件。
3. 后台依次排队、解析、建立向量索引。可按状态/名称筛选、批量重试处理失败文件或批量删除。上传失败与处理失败分别显示。
4. 全部文件可检索后点击“发布知识库”，普通账号才能读取、下载原文和在聊天中选择这些资料。取消发布会撤销这些读取权限，维护文件前必须取消发布。原有私有资料保持私有，不自动发布。管理员可从“未分组文件”中勾选历史文件，选择草稿知识库并“移动所选”；文档 ID 和现有索引保持不变。
5. 聊天端仅选择已就绪资料（每个对话最多 12 个），没有上传、创建或删除入口。后续轮次保留范围；历史对话恢复选择，新对话重新选择。
6. 回答来源按钮可打开片段原文与页码/标题路径；列表与 3D 视图使用同一份来源数据。桌面展示完整路径，手机聚焦所选片段的路径，可在下方列表切换。
7. 流式输出直接跟随当前滚动容器的底部；上翻后保留阅读位置，点击“滚动到最新”恢复跟随。不对每批文字使用平滑滚动。

没有选择资料时使用普通聊天。已选择资料但处理失败、尚未就绪或模型配置发生变化时，接口会明确提示，不静默使用其他用户资料或旧模型的向量。

可先使用 `examples/knowledge` 下的两份虚构资料演示跨文件比较与引用，不必上传私人文件。

## 已实现的链路

- 原文件保存在持久目录，数据库保存所有者、哈希、分组、状态和任务。
- 独立 Node worker 解析文件；PDF 保留页码，Markdown 保留标题路径。使用结构递归或语义边界形成父块，再用 LangChain 切分检索子块并保留定位信息；预算按 Unicode 字符，非精确模型 Token。
- 默认阿里云 `text-embedding-v4`、1024 维，分批写入 PostgreSQL / pgvector。使用中文全文与向量混合召回、RRF 及可选阿里云模型重排；向量侧仍为授权范围内精确排序，未引入 HNSW。
- 查询在 SQL 中先限定所有者或已发布共享权限、已选文档、就绪状态和向量配置，再计算余弦相似度；0.25 为首版筛选阈值，不代表答案置信度。每个查询最多返回 6 个片段，本轮累计最多 12 个来源。
- 简单问题直接检索；含上下文指代的追问、比较与多问等情况可调用模型改写/拆分，最多 3 个检索问题。模型可通过内置工具补查一次，或读取已命中片段的有限相邻上下文。
- 模型调用最多 5 轮（包含启用时的改写调用），工具/准备步骤最多 6 次，补查、重复调用及总时限均有约束；最后一轮关闭工具，保留回答机会。
- 规范化并核对引用 ID 与本轮召回范围；这一检查验证来源身份，不等于自动证明所有结论和原文语义一致。
- AgentRun / AgentStep 保存实际步骤、状态、来源和耗时；SSE 带本次请求序号，RAG 事件关联 runId。客户端停止时保留已收到的部分回复。

## 3D 来源图

图形由本项目自行编写，使用 Three.js / React Three Fiber，未复制 GitHub 项目的图形代码。使用实际的“问题 → 检索步骤 → 命中片段 → 原文件”数据，以主题适配的卡片与曲线展示；源节点支持拾取、高亮和原文联动，触屏下聚焦单条路径。原生 Canvas 纹理用于标签，静止时按需绘制，关闭视图时卸载并释放资源。

三维坐标只表示稳定分组布局，不是向量降维结果，也不是 GraphRAG。默认使用来源列表；3D 组件按需加载，WebGL 不可用时回退到等价列表。移动端与深浅主题可使用同一套来源数据。

## 本机启动与部署

先按 `.env.example` 填写数据库、模型与 JWT 配置，再执行：

```powershell
npm ci
npx prisma generate
npm run db:migrate
npm run build
npm run start -- --hostname 127.0.0.1 --port 3100
```

在另一个终端、相同项目目录下运行：

```powershell
npm run rag:worker
```

Web 与 worker 必须访问同一数据库及同一个持久化文件目录。默认目录是项目下 `.data/rag`（已忽略提交），可通过 `RAG_STORAGE_DIR` 配置。部署到其他机器时同时备份数据库和原文件目录；不能只迁移向量表。

当前部署模型是一个 Web 服务配一个常驻 worker；可以运行多个 worker，通过 PostgreSQL 行锁领取任务和租约防止重复提交。队列在进程中断后保留，超过 5 分钟的失效租约可回收。正常处理会刷新心跳；原子替换分块使重试不叠加旧结果。默认不无限重试异常任务，用户可在界面重试。

生产主机应由服务管理器或容器管理 Web/worker 的启停和重启，挂载持久目录。当前在本机启动的进程不是系统开机服务；电脑或进程停止后需重新启动上述两个服务。不能直接将本地文件方案部署成无常驻 worker、无共享磁盘的纯 Serverless 应用。

构建使用 Next.js 支持的 Webpack 模式；本机 Turbopack 生产构建遇到编译子进程提前退出，开发服务器仍可使用默认构建器。

## 配置与限制

- Embedding 默认复用当前阿里云地址/密钥；也可独立配置 `EMBEDDING_API_KEY`、`EMBEDDING_BASE_URL`、`EMBEDDING_MODEL`，维度固定 1024。
- 修改向量模型或地址后，文件库提示重新索引；不得混用不同配置的向量。更改向量维度需要额外数据库迁移，不应仅修改环境变量。
- 单文件最多 10 MB，PDF 最多 300 页，单文件最多 1600 个分块，单个管理员最多 200 个文件；单批最多 50 个。超限需拆分或删除旧文件。
- 暂不支持扫描件 OCR、图片理解、网页采集和复杂表格识别。读取 PDF 的文本顺序取决于 PDF 文本层，复杂版式需要额外验证。
- 文件内容不可在线编辑；管理员可上传新版本，成功后自动切换会话选择，失败时保留旧版。分组支持创建与选择，暂未提供知识库重命名或删除入口。
- 删除文件会清理分块、任务及会话选择关联；历史回答中的文字不会被重写。来源不可用时显示错误与当时保留的摘录，不伪装为仍能打开原文。
- 刷新可恢复已保存的回答和执行记录；不承诺正在生成的模型请求继续在后台运行。上传接口接收的文件会继续在后台处理；离开管理页面会取消尚未完成的前端上传，不取消已入队任务。
- 现有公开分享页只输出对话文字，不开放原文件或分块读取接口；来源 API 始终需要登录，并检查所有权或当前发布状态；普通账号无资料写入权限。历史回答中已保存的摘录和文字不会因取消发布而重写。

## 验证

```powershell
npm test
npm run lint
npm run test:e2e
npm run rag:check
# 需 Web/worker 已启动，会调用真实模型并产生相应费用：
npm run rag:smoke
```

`rag:smoke` 使用独立临时账号和虚构文本/PDF，验证实际入库、跨文件引用、追问、权限隔离、错误恢复、删除与生产页面，并在结束后按本次 ID 清理测试数据。报告位于 `reports/rag-smoke.json`。该脚本不是大规模准确率评测，也没有操作已有用户资料。

42 题固定样本评测、混合检索和重排已实现；更大规模与真实业务评测仍待扩充，不能把样例指标当作答案准确率或容量保证。
